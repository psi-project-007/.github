# Contributing

Thanks for wanting to help! Here's how it works.

## Before you start

- For anything bigger than a small fix, open an issue first so we can agree on the approach.
- Security issues never go in public issues. See [SECURITY.md](SECURITY.md).

## Making a change

1. Fork the repository and create a branch from `main`.
2. Keep it to **one change per pull request**.
3. Add or update tests. A change without tests won't be merged.
4. **Sign your commits** ([how to sign](https://docs.github.com/en/authentication/managing-commit-signature-verification/signing-commits)).
5. Open a pull request and fill in the template.

## Ground rules

- Never commit secrets: no keys, tokens, passwords or real user data.
- Keep code readable. Clear beats clever.
- Be respectful in reviews and discussions ([Code of Conduct](CODE_OF_CONDUCT.md)).

By contributing, you agree your work is released under the repository's license.
