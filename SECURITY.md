# Security policy

We take security seriously, especially in projects that guard people's secrets.

## Reporting a vulnerability

**Please don't open a public issue.**

1. Go to the affected repository.
2. Open the **Security** tab and click **Report a vulnerability**.
3. Tell us what you found, how to reproduce it, and what impact you expect.

We'll reply within **7 days** and keep you updated until it's fixed. If you'd like, we'll credit you when the fix is released.

## Supported versions

Until a project reaches 1.0, only the latest code on `main` gets security fixes.

## Please don't

- Access, change or delete data that isn't yours.
- Run tests that could harm the service or other people (spam, denial of service).
- Share the issue publicly before we've released a fix.

Thank you for helping keep everyone safe. 🙏
